# Vulnerability Assessment Report – OWASP Juice Shop

## Objective
Performed basic web vulnerability assessment using Browser DevTools.

## Tools Used
- Firefox DevTools
- Kali Linux
- OWASP Juice Shop

## Findings
1. Missing Content-Security-Policy Header
2. Server Information Disclosure
3. X-Frame-Options Present

## Risk Levels
- Missing CSP → Medium
- Server Disclosure → Low
- X-Frame-Options Present → Safe

## Outcome
Successfully analyzed HTTP security headers and identified security weaknesses.
